## 工作原则

- 先明确主题问题，再决定数据和图形，不为使用图表而搜集数据。
- 类型标签允许组合：数据逻辑类型、表现媒介、视觉风格、图表形式、叙事结构分开标注。
- 每个数据字段保持原子性；同一列字段语义、类型、单位一致，每个单元格一个值。
- 原始数据、清洗数据、分析数据、设计映射数据分层保存，不覆盖原始来源。
- 所有关键数据记录来源、采集时间、口径、许可和处理过程。
- 设计表达优先，但不能通过视觉夸大、隐瞒或扭曲数据含义。
- 第 7 阶段暂作为测试框架占位，具体规则待后续共同补充。
