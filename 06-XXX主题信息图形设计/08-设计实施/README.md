# 08 设计实施

## 目标

把已验证的数据、叙事结构和视觉编码转化为完整的信息图形设计，并完成准确性、可读性、版权与输出质量检查。

## 实施步骤

1. **内容脚本：** 确认标题、导语、章节、数据注释、结论与来源。
2. **信息草图：** 先用低保真框架确定阅读顺序、模块比例和信息密度。
3. **版式系统：** 建立画幅、网格、边距、栏宽、基线与层级。
4. **视觉资产：** 制作图表、地图、图标、插画、照片处理和标注。
5. **数据绑定：** 所有图形与最终数据表核对，保留计算过程。
6. **视觉统一：** 检查色彩、字体、线宽、符号、照片风格与图例一致。
7. **用户测试：** 观察读者能否找到重点、正确解读图例和理解结论。
8. **事实校对：** 核对数值、单位、日期、地名、引用、版权与来源。
9. **输出交付：** 按印刷/屏幕要求输出文件，并保留可编辑源文件。
10. **归档复盘：** 保存最终稿、源文件、数据版本、字体/素材许可与设计决策。

## 推荐子目录

- `content/`：文案脚本、标题、注释与来源。
- `wireframes/`：信息结构草图、版式线框。
- `visual-assets/`：自制图标、插画、照片处理稿。
- `charts-maps/`：统计图表与地图源文件。
- `source-files/`：AI、PSD、Figma 等可编辑文件说明。
- `exports/`：PDF、PNG、SVG 等交付输出。
- `review/`：校对、测试反馈与修改记录。

## 交付检查

- [ ] 所有数据与数据集版本一致。
- [ ] 所有图表单位、图例、尺度完整。
- [ ] 结论不超出证据支持范围。
- [ ] 字体、图片、图标和地图素材许可清楚。
- [ ] 印刷文件检查出血、色彩模式、分辨率和字体。
- [ ] 屏幕文件检查尺寸、可读性和压缩质量。
- [ ] 源文件、数据、导出稿和版本记录齐全。

## 复盘

记录有效方法、问题、未完成事项，以及应回写到仓库 `01-信息图形数据逻辑/` 或 `02-信息图形类型案例/` 的通用知识。
