# 05 叙事框架搭建

## 目标

将基础数据集中的字段组合成有明确主题的问题、比较关系或空间/时间叙事。字段组合不是简单拼接，而是说明“这些字段一起能回答什么问题”。

## 字段组合示例

- 名称 + GPS 坐标 → 地图上的地点定位与空间分布。
- 地点名称 + GDP 数值 + 年份 → 某地经济规模及其时间变化。
- 事件名称 + 起止日期 → 事件持续时间与阶段时间轴。
- 对象名称 + 分类标签 + 属性 → 分类图鉴或编目结构。
- 关键词 + 词频 → 词频概览/词云（词云强调频次视觉，不适合精确比较）。
- 照片引用 + 地点 + 拍摄日期 → 具有空间与时间索引的照片叙事。

## 叙事构建步骤

1. 写出核心叙事命题（一句话）。
2. 把命题拆成读者需要回答的子问题。
3. 为每个子问题匹配字段组合。
4. 判断组合能否直接支持结论，是否需要计算、聚合或补充字段。
5. 设计阅读顺序：总览、分组、比较、细节、结论。
6. 标出证据不足、相关不等于因果、样本偏差等风险。

## 数据组合规则

- 所有参与组合的字段必须能通过主键或明确关系连接。
- 组合前确认时间粒度、空间粒度、单位、统计口径一致。
- 对数值比较需明确基准、分母和单位。
- 位置+数值可以形成地图专题表达，但需判断是否适合比例符号、分级设色或图表辅助。
- 不可仅凭两个字段相关就写出因果结论。

## 阶段出口

形成主叙事、分叙事、字段组合、计算步骤、建议图表和每条结论的证据来源。
