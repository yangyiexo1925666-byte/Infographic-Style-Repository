# 01 前期调研

## 目标

确定选题的研究边界、受众需求、信息价值与设计机会，避免在主题尚未明确时直接进入视觉制作。

## 调研内容

1. **主题背景：** 起源、发展、现状、相关概念与争议。
2. **范围界定：** 地域、时间、对象、行业、样本边界及排除项。
3. **受众分析：** 受众已有认知、信息需求、阅读环境与理解门槛。
4. **问题定义：** 读者最需要回答的 3–5 个问题，最终收敛为核心问题。
5. **同类案例调研：** 收集信息图形、数据可视化、编辑设计、地图、图鉴、信息海报等参考。
6. **数据可得性预判：** 初步判断是否有公开数据、文献、可采集信息与版权风险。
7. **设计机会：** 找出已有表达的不足，以及本项目可以建立的独特视角。
