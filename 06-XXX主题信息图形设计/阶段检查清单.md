# 阶段检查清单

- [ ] 01 前期调研：主题范围、受众、背景、竞品/参考案例、核心问题。
- [ ] 02 主题内容分析：与大模型讨论并确认主导数据逻辑、表现媒介、风格、图表和标签。
- [ ] 03 数据搜集：公共数据、文献文本、自建数据均有来源记录与许可说明。
- [ ] 04 基础数据集：字段原子化、每格单值、类型单位统一、缺失值有规则。
- [ ] 05 叙事框架：明确主叙事命题，字段组合与结论之间有证据关系。
- [ ] 06 视觉编码：视觉变量与数据字段映射明确，图例完整，设计表达一致。
- [ ] 07 信息轮盘测试：测试维度与通过标准待共同补充。
- [ ] 08 设计实施：完成草图、版式、图形、校对、输出与归档。
- [ ] README、索引、来源和版本记录已更新。
