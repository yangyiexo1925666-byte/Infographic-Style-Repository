# 数据伦理与图形诚实

## 1. 数据质量是设计基础

信息图表的可信度首先取决于数据本身。课程材料归纳的数据质量维度如下：

| 维度 | 核查问题 |
|---|---|
| 权威性 | 来源是否为官方机构、学术研究或可信组织？ |
| 准确性 | 数据是否真实，是否存在录入、测量或转录错误？ |
| 时效性 | 数据更新时间是否符合分析目标？ |
| 完整性 | 覆盖范围、缺失值和样本是否得到说明？ |
| 一致性 | 不同来源的单位、定义、时间范围和统计口径是否可比？ |

“一致性”是实际整理时建议补充的检查维度。数据质量问题不会因为视觉设计精美而消失。

## 2. 数据使用的伦理原则

- **诚实性：** 不伪造、篡改或歪曲数据。
- **透明性：** 标注来源、统计口径、时间范围、单位、清洗和计算方法。
- **问责性：** 对数据使用、解释和传播结果负责。
- **公平性：** 避免选择性呈现造成群体污名化或片面结论。
- **可追溯性：** 保留原始来源和处理记录，便于复核。

“垃圾进，垃圾出”（Garbage In, Garbage Out）：输入数据的缺陷可能沿分析和可视化流程传递到最终结论。

## 3. 图形诚实：常见误导风险

| 风险 | 可能造成的误读 | 改进方式 |
|---|---|---|
| 截断纵轴 | 夸大柱长或数值差异 | 说明轴范围；比较长度时通常使用零基线 |
| 面积误用 | 视觉面积与数据比例不一致 | 按面积映射数值，提供图例 |
| 颜色误导 | 造成错误分类、强弱或情绪暗示 | 建立一致色彩语义并说明分级 |
| 省略数据 | 使总体情况或比较结果失真 | 公开筛选条件、缺失值和排除规则 |
| 口径不一致 | 把不可比数据并置比较 | 统一定义、单位、时间和样本口径 |
| 3D/透视效果 | 透视、遮挡和体积造成错误判断 | 除非有必要，不使用装饰性 3D |

## 4. 谎言因子 Lie Factor

课程材料引用 Edward Tufte 的谎言因子概念：

**Lie Factor = 图形中呈现的效应大小 ÷ 数据中的实际效应大小**

其核心是比较视觉表达所暗示的变化幅度与数据真实变化幅度。理想情况下二者一致，因子接近 1；明显偏离 1 可能意味着图形夸大或缩小了数据变化。

使用时必须明确“效应大小”的测量口径。例如不能随意将长度变化与面积变化混为一谈；对复杂图形，应说明如何测量视觉呈现的变化。Lie Factor 是诊断视觉失真的思考工具，不是覆盖所有图表类型的自动审查标准。

## 5. 数据/油墨比 Data-Ink Ratio

课程材料引用 Tufte 的数据/油墨比思想：

**Data-Ink Ratio = 用于呈现数据的墨水量 ÷ 图表所用总墨水量**

设计启示：
- 保留真正承载数据或帮助解释数据的线条、标记和标签。
- 减少重复边框、无意义网格、装饰性图标和不必要的阴影。
- 不能为了追求高比率而删除必要的轴、单位、图例和上下文。
- “少即是多”不是绝对规则，必要的辅助元素可以提升可读性与可解释性。

## 6. 图表垃圾 Chartjunk

图表垃圾指对理解数据没有帮助、甚至干扰或扭曲信息的视觉装饰，例如过度立体化、无意义纹理、繁复背景、重复图标和过度装饰。

判断一个元素是否应保留，可问：
1. 它是否编码数据？
2. 它是否帮助定位、分组或解释？
3. 它是否改善可读性或可访问性？
4. 删除它是否会损害理解？

如果一个元素只增加视觉复杂度而不增加信息价值，应考虑删除或弱化。

## 7. 简化形式，不简化事实

信息设计需要降低理解难度，但不应通过删减关键证据来制造表面上的清晰。

- 可以简化阅读路径、图例结构和视觉装饰。
- 可以把细节放入附录、注释或交互层。
- 不应隐去改变结论的样本、数据区间或不确定性。
- 对估算、预测、插值和推断应明确标注，不应伪装成实测事实。

## 8. 发布前伦理核查

- [ ] 数据来源可靠且可追溯？
- [ ] 单位、时间范围、样本和统计口径清楚？
- [ ] 数据清洗、筛选和缺失值处理有记录？
- [ ] 图表尺度、基线和面积编码是否诚实？
- [ ] 颜色与图形是否暗示未经证实的关系？
- [ ] 是否遗漏会改变结论的重要数据？
- [ ] 标题是否夸大或超出数据能够支持的结论？
- [ ] 不确定性、限制和推断是否明确说明？
