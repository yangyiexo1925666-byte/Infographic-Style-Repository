# 数据类型与基础图表选择

## 1. 四种基本数据类型

判断数据类型，是选择统计图表和视觉编码的起点。

| 数据大类 | 类型 | 定义 | 示例 | 常见分析方式 |
|---|---|---|---|---|
| 定性 | 名义型 Nominal | 无内在顺序的类别 | 地区、品牌、颜色、血型 | 分类、计数、构成 |
| 定性 | 顺序型 Ordinal | 有顺序，但相邻等级间隔不一定相等 | 满意度、教育程度、等级 | 排序、等级分布 |
| 定量 | 离散型 Discrete | 通常通过计数获得的可数数值 | 人数、订单数、车辆数 | 计数、频数比较 |
| 定量 | 连续型 Continuous | 通常通过测量获得，可在区间内取连续值 | 身高、体重、温度、时间 | 分布、趋势、相关 |

### 1.1 判断流程

1. 先判断变量是否为类别。
2. 若为类别，检查是否存在自然顺序：无顺序为名义型，有顺序为顺序型。
3. 若为数值，判断它来自计数还是测量：计数通常为离散型，测量通常为连续型。
4. 记录精度与操作定义。同一变量可能因记录方式不同而表现为不同尺度，例如年龄可以按整岁记录，也可以按连续时间测量。

> 不要只凭字段名称判断数据类型；应结合实际测量方式、记录精度和分析目的。

## 2. 数据类型与图表的启发式对应

| 数据类型 | 常见首选 | 可考虑的替代 | 需要谨慎的形式 |
|---|---|---|---|
| 名义型 | 条形图/柱状图、点图 | 饼图（少量类别）、树状图 | 用折线暗示无序类别的连续趋势 |
| 顺序型 | 排序条形图、点图、热力图 | 面积图（有明确序列时） | 忽略等级顺序或把等级间距当作等距 |
| 离散型 | 柱状图、点图 | 表格、按组统计的条形图 | 类别数量过多时使用面积图 |
| 连续型 | 直方图、折线图、散点图 | 箱线图、面积图 | 用饼图表达连续变量 |

该表是课程层面的快速参考，不是绝对规则。图表选择还取决于变量数量、统计任务、分布形态、样本量、读者背景和媒介。

## 3. 六类基础图表

### 3.1 柱状图/条形图 Bar Chart

**用途：** 比较不同类别的数值大小。

**适用：** 名义型类别、离散计数、经过分组的顺序数据。

**设计要点：**
- 比较长度时通常从零基线开始；若使用截断轴，必须明确标示并评估误导风险。
- 类别排序应服务于任务：按数值排序、自然顺序或逻辑分组。
- 类别较多时考虑横向条形图、分组或筛选。
- 保持条宽与间距一致，避免 3D 透视影响长度判断。

**常见错误：** 类别无序、轴截断不说明、标签拥挤、使用装饰效果扭曲柱长。

### 3.2 折线图 Line Chart

**用途：** 展示连续序列中的变化趋势，常见为时间序列。

**设计要点：**
- 横轴顺序和间隔应符合数据的实际时间或连续尺度。
- 多条线应控制数量并使用清晰图例或直接标注。
- 标记关键节点、异常或重要区间。
- 缺失数据和不连续时间段不应被无提示地连成连续变化。

**常见错误：** 将无序类别连线、时间间隔不一致、线条过多、把插值误当成实测数据。

### 3.3 饼图 Pie Chart

**用途：** 展示少量类别构成的整体占比。

**适用条件：**
- 类别数量较少；
- 各部分构成同一整体，口径一致；
- 主要任务是粗略识别构成，而不是精确比较。

**设计要点：** 标明总量或百分比，扇区排序与颜色编码保持一致。类别多、比例接近或需要精确比较时，优先考虑排序条形图。

### 3.4 散点图 Scatter Plot

**用途：** 探索两个定量变量之间的关系、聚集模式和离群值。

**设计要点：**
- 横纵轴均需标注变量、单位与尺度。
- 点重叠时可使用透明度、抖动或密度辅助表达。
- 趋势线应说明拟合方法或避免暗示因果关系。
- 若用点大小编码第三个变量，需明确图例和面积映射。

### 3.5 面积图 Area Chart

**用途：** 展示随连续尺度变化的总量或构成。

**形式：**
- 普通面积图：强调总量变化。
- 堆叠面积图：展示总量及组成部分的变化。
- 百分比堆叠面积图：展示各组成部分的相对占比变化。

**设计要点：** 关注基线、堆叠顺序、透明度与类别数量。堆叠后除底层外，各层的精确比较可能较困难。

### 3.6 表格 Table

**用途：** 查询精确数值、查看多维字段与详细记录。

**设计要点：**
- 文本通常左对齐，数值按位数或小数点对齐。
- 控制列宽，避免表格过密。
- 使用清晰表头、单位、排序和必要的斑马纹。
- 长表可固定表头；关键值可通过字重或有限强调突出。

## 4. 按读者任务选择图表

| 读者任务 | 优先考虑 | 选择依据 |
|---|---|---|
| 比较类别数值 | 排序条形图/柱状图 | 长度便于比较 |
| 观察时间变化 | 折线图 | 适合呈现连续趋势 |
| 展示少量类别构成 | 饼图或堆叠条形图 | 表现整体与部分关系 |
| 探索变量关系 | 散点图 | 观察相关、聚类与异常 |
| 展示总量及构成随时间变化 | 面积图/堆叠面积图 | 强调总量或构成变化 |
| 查询精确数据 | 表格 | 支持逐项查找与核对 |
| 比较分布 | 直方图、箱线图等 | 关注分布形态而非单一总值 |

## 5. 图表选择决策流程

1. 明确读者要完成的任务：比较、趋势、构成、关系、分布还是查询。
2. 确认变量数量与数据类型。
3. 判断是否存在时间、空间、等级或整体—部分关系。
4. 选择能直接支持该任务的图表。
5. 检查尺度、基线、排序、单位、缺失值和图例。
6. 用目标读者进行快速阅读测试；若读者必须反复搜索或心算，重新组织图表。

## 6. 图表与表格结合

- 演示与报告正文：用图表呈现主要趋势和关系。
- 附录或详细查询区：用表格保留完整记录与精确数值。
- 不应为了追求“可视化”而把所有信息都转换为图表；表格在精确查询任务中可能更有效。
