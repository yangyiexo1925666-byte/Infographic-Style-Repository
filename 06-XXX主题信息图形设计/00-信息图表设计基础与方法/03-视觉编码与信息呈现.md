# 视觉编码与信息呈现

## 1. 视觉编码的定义

视觉编码是将数据字段、类别、数值或关系映射到可见视觉属性的过程。编码必须具有可解释的语义：读者应能理解颜色、位置、长度、面积、形状、符号和文字分别代表什么。

## 2. 常见视觉变量

| 视觉变量 | 常见用途 | 使用提醒 |
|---|---|---|
| 位置 Position | 排序、精确比较、空间关系 | 轴、基线和坐标尺度必须明确 |
| 长度 Length | 数值大小、差异比较 | 保持统一尺度与基线 |
| 角度/方向 Angle / Orientation | 方向、分组、方向性差异 | 精确比较通常不如位置和长度直观 |
| 面积 Area | 总量、规模或构成 | 需要明确面积与数值的映射关系 |
| 色相 Hue | 类别区分 | 避免类别颜色过多、语义冲突 |
| 明度/饱和度 Value / Saturation | 顺序、强弱、强调 | 需检查对比度与色觉可辨识性 |
| 形状 Shape | 类别识别、符号区分 | 类别数量宜有限，图例应清楚 |
| 纹理/图案 Texture | 分组、区域区分 | 避免密集纹理造成视觉噪声 |
| 尺寸 Size | 强调、数量或层级 | 必须说明编码的是长度、面积还是体积 |

Jacques Bertin 的《图形符号学》（*Sémiologie graphique*，1967）是视觉变量理论的重要经典来源。具体视觉变量的组合应根据数据尺度、媒介与读者任务决定。

## 3. 感知准确度与编码选择

课程材料引用 Cleveland 与 McGill 关于图形感知任务的研究，给出位置、长度通常优于角度、面积及颜色饱和度等编码的教学性排序。

**实践启示：**
- 需要精确比较时，优先使用共同尺度上的位置或长度。
- 面积、气泡大小和颜色强度更适合表达大致规模或模式，不宜让读者据此进行高精度估计。
- 气泡图若用圆面积编码数值，应按面积而不是半径线性映射；同时提供图例和必要的数值标签。
- 视觉感知排序受具体任务、图表设计和观察条件影响，不应被当作适用于所有情境的固定公式。

## 4. 视觉层级与信息组织

视觉层级应帮助读者回答“主题是什么、最重要的发现是什么、证据在哪里、细节如何查询”。

常见层级：
1. 主题标题与核心结论；
2. 关键指标或主要图表；
3. 辅助比较、分组和解释；
4. 图例、注释、数据来源与方法说明。

可使用字号、字重、位置、留白、色彩和对齐建立层级。不要只依赖颜色表达重要信息，避免色彩对比不足或色觉差异导致信息丢失。

## 5. 字体与排版

| 项目 | 设计建议 |
|---|---|
| 标题 | 醒目、简洁，准确概括主题或结论 |
| 正文 | 清晰易读，适合持续阅读 |
| 数据字体 | 数字辨识度高；需要对齐时可考虑等宽数字 |
| 视觉层级 | 用字号、字重、颜色和位置建立阅读顺序 |
| 信息密度 | 控制拥挤，避免把所有内容放在同一层级 |
| 对齐与留白 | 建立秩序、分组和呼吸空间 |
| 风格一致性 | 字体、标点、单位、图例和标注规则统一 |

## 6. 降低读者认知负担

读者在理解图表时可能需要搜索目标数据、记住数值、排序并进行比较。设计者可以提前完成这些工作：

- 通过排序、分组和直接标注减少搜索。
- 通过共同基线和一致尺度降低比较难度。
- 将关键结论放在显著位置，避免让读者在多个区域间反复寻找。
- 使用明确标题、图例和单位，减少猜测。
- 将概览与细节分层呈现，避免一次性展示过多信息。

课程材料提及工作记忆容量的“7±2”说法。该说法属于早期概括，不应作为所有界面或图表的硬性容量标准；实际认知负担受任务、熟悉度、分组方式和信息复杂度影响。

## 7. 信息筛选与展示/隐藏

信息筛选是为了突出与任务相关的内容、控制阅读负担，不等于篡改或掩盖事实。

合理筛选：
- 将次要细节放入注释、附录或交互层。
- 使用分组、折叠和层级导航组织复杂内容。
- 明确说明数据范围、筛选条件和排除规则。

不合理隐藏：
- 选择性省略会改变结论的数据。
- 隐藏不利样本或改变统计口径却不说明。
- 通过视觉权重让读者忽略重要限制。

## 8. 视觉编码检查表

- [ ] 每个视觉变量是否对应明确的数据字段或语义？
- [ ] 类别、顺序与数值尺度是否匹配？
- [ ] 精确比较是否优先使用位置或长度？
- [ ] 面积、气泡大小和颜色强度是否提供图例或数值辅助？
- [ ] 色彩是否可区分，并考虑色觉差异与对比度？
- [ ] 标题、主图、辅助信息和注释是否形成清晰层级？
- [ ] 版式是否减少搜索、记忆、排序和比较负担？
- [ ] 信息筛选是否透明，未改变事实含义？
