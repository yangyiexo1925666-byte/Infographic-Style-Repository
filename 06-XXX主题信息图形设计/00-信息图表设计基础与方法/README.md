# 信息图表设计基础与方法

本目录整理信息图表设计的通用基础知识与方法，连接数据逻辑、统计图表、视觉编码、信息叙事和用户体验。内容依据课程《信息图表设计导论》《数据类型与基础图表》《信息图形类型学》整合，并对重复知识进行归并。

## 知识结构

1. [信息图表基础与历史](./01-信息图表基础与历史.md)：定义、核心使命、DIKW、四层模型与发展脉络。
2. [数据类型与基础图表选择](./02-数据类型与基础图表选择.md)：四类数据、六类基础图表、选择矩阵与决策逻辑。
3. [视觉编码与信息呈现](./03-视觉编码与信息呈现.md)：视觉变量、感知准确度、排版层级与降低认知负担。
4. [数据伦理与图形诚实](./04-数据伦理与图形诚实.md)：数据质量、数据/油墨比、图表垃圾、谎言因子与信息筛选边界。
5. [交互信息设计与用户体验](./05-交互信息设计与用户体验.md)：静态/交互选择、交互模式、用户中心设计。
6. [设计工作流与评估清单](./06-设计工作流与评估清单.md)：从数据收集到读者测试的完整流程。
7. [经典案例与拓展资源](./07-经典案例与拓展资源.md)：历史案例、应用案例、书目、网站与工具。

## 使用原则

- 先识别数据类型、信息关系和读者任务，再选择图表与视觉形式。
- 区分课程归纳、理论来源和设计建议；选择矩阵是启发式参考，不是不可违反的规则。
- 视觉编码必须具有明确语义，装饰不能改变数据含义。
- 记录数据来源、统计口径、单位、时间范围、清洗步骤和限制。
- 具体项目应根据读者、媒介、设备、可访问性和使用情境调整表达方式。
