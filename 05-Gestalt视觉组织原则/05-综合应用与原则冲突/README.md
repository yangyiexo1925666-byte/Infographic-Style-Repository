# 综合应用与原则冲突

格式塔原则往往同时作用于同一画面。设计分析不能只寻找单一原则，而应判断多种线索如何共同塑造知觉组织。

## 本目录内容
- [原则之间的关联](./原则之间的关联.md)：原则之间的协同、互补与层级关系。
- [原则冲突与取舍](./原则冲突与取舍.md)：视觉线索不一致时的诊断和处理方法。
- [设计经验总结](./设计经验总结.md)：从案例和实验中提炼有条件的经验结论。
- 多原则组合设计案例：实际录入组合案例时再建立对应文件。

## 使用方法
先说明设计目标，再列出各原则对应的画面证据，随后分析线索权重和可能的误读，最后通过测试确认组织效果。不要只用原则名称替代分析。
