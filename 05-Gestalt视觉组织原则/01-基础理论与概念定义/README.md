# 基础理论与概念定义

本目录记录格式塔理论背景、核心术语与首期收录的 12 项原则。

## 阅读前先区分三个层级

- **总体组织倾向**：Prägnanz 描述知觉系统倾向于形成较稳定、规则、简洁的整体组织。
- **局部分组线索**：接近、相似、连续、闭合、共同命运、对称、平行、共同区域、连接性、同步等，说明视觉元素在何种关系下容易被组织为群组。
- **图底组织**：Figure-Ground 讨论视觉场如何分化为被关注的形体与其背景，以及图底关系如何转换。

以上层级彼此相关，但不可简单视为同一层级的 12 条平行规则。
