# 设计分析与拆解

本目录用于对平面设计、信息图形、品牌标志、编辑版式、UI 与动态作品进行结构化拆解。

## 分析流程
1. 明确作品目标、受众、媒介和观看情境。
2. 记录画面事实：元素、位置、距离、形态、颜色、边界、方向和动态关系。
3. 判断哪些格式塔线索在起作用，并指出证据。
4. 分析原则之间如何协同或冲突。
5. 推断其对识别、分组、层级、阅读路径和记忆的影响。
6. 提出可验证的优化方向。
