# 多原则综合分析模板

## 1. 作品与任务
- 作品名称/作者/年份/媒介：
- 设计目标与用户任务：
- 来源：

## 2. 组织结构总览
描述主体、背景、主要信息组、阅读路径和视觉层级。

## 3. 原则作用矩阵
| 原则 | 画面证据 | 作用对象 | 组织效果 | 证据强度 |
|---|---|---|---|---|
| | | | | |

## 4. 协同关系
哪些原则强化同一分组或阅读路径？例如接近与相似是否共同指向同一类别？

## 5. 冲突关系
是否出现颜色相似但空间分离、边界包围但语义不同、连续路径与分组边界竞争等情况？

## 6. 用户理解与验证
提出观察任务、可用性测试或对照版本，检验组织是否按预期被理解。

## 7. 设计结论
提炼可迁移经验，同时写明适用条件与限制。
