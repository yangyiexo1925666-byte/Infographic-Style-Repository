# Gestalt 格式塔视觉组织原则资料库

本目录用于系统整理格式塔（Gestalt）视觉组织理论及其在平面设计、信息图形、版式、标志、UI 与动态视觉中的应用。资料库由理论定义、案例库、设计拆解、实践记录和综合应用五部分组成。

## 收录范围与分类说明

本资料库首期采用 12 项工作分类。它是面向设计学习与实践的知识组织方案，不代表学术界存在唯一、固定且封闭的“格式塔法则总数”。不同研究会按研究对象、实验传统与术语层级采用不同分类。

## 推荐学习路径

1. 先阅读基础理论概述，理解“知觉组织”与“分组原则”的区别。
2. 逐项阅读原则定义，记录可观察的视觉线索与适用条件。
3. 在案例库录入真实作品，区分客观描述、来源信息与个人解释。
4. 使用设计拆解模板分析作品，判断哪些原则共同发挥作用。
5. 通过实践记录检验原则在具体任务中的效果，再回写经验总结。

## 研究与使用规范

- 不把格式塔原则当作机械套用的版式公式；设计判断需结合任务、媒介、观看距离、文化语境与信息复杂度。
- 区分知觉现象、理论解释和设计建议。设计案例中的相似效果不自动证明其由某一原则单独造成。
- 案例必须记录作者/机构、作品名称、年份（如可查）、原始来源链接、访问日期及版权/使用说明。
- 未经授权不将网络图片重新分发到仓库；优先保存链接、缩略图说明和分析文字。
- 当研究发现术语分类存在差异时，在文档中注明来源和差异，不强行统一为单一说法。
