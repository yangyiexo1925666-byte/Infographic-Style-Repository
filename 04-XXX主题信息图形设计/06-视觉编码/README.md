# 06 视觉编码

## 目标

将叙事字段转译为可读、准确且有设计表现力的视觉系统。此阶段偏重设计表达，但每种视觉形式必须有清楚的语义映射。

## 视觉编码维度

- **点：** 位置、数量、节点、密度；点大小需明确是否表示数值。
- **线：** 路径、连接、流向、时间、边界、关系；线宽/线型需有含义。
- **面：** 区域、分类、占比、范围、容器；面积编码需有量化依据。
- **体：** 高度、体积、层叠、空间结构；透视与遮挡不能破坏比较。
- **色彩：** 类别色、顺序色、发散色、强调色；建立色彩语义和可访问性检查。
- **行距/字距/字号：** 控制文字层级、阅读节奏、密度与信息分组。
- **图像/照片：** 作为证据、对象识别、场景氛围或叙事主体；照片需有来源、说明和索引。
- **图形/插画：** 结构解释、过程说明、对象概括；明确写实程度与统一风格。
- **统计图形：** 柱、线、点、面积、矩阵、地图等，严格匹配变量尺度与比较任务。
- **ISO/标准符号：** 用于标准化识别时核对具体标准、版本和授权；不能把普通图标误称为 ISO 符号。
- **象形符号：** 重复数量、大小或排列表达数据时，需有明确映射和图例。

## 视觉表达决策

先问数据需要读者比较什么，再选择视觉变量：
- 类别区分：形状、色相、分组。
- 数值大小：位置、长度、面积（谨慎）、大小。
- 顺序/时间：位置、方向、线性排列。
- 空间位置：地图坐标与区域。
- 文本主题：层级、字重、字号、标注与索引。
- 照片信息：网格、图注、地点/时间标签、照片序列。

## 阶段出口

完成视觉编码表、色彩与字体系统、图表规范、图标/照片规则和关键版式草图。
