# 03 数据搜集

## 数据来源的三条路径

### A. 公共数据集

政府开放数据、统计年鉴、开放地图、科研数据平台、国际组织数据库、公共 API 等。

记录：数据集名称、发布机构、URL、发布日期/更新时间、下载日期、许可协议、字段说明、统计口径、地理/时间范围。

### B. 文本文献

论文、书籍、年鉴、报告、新闻档案、地方志、机构网页、访谈文本等。

记录：作者、标题、出版机构、年份、页码/章节、URL/DOI、引用片段、提取字段、是否为二手来源。文本摘录与研究者编码应分开保存。

### C. 自建数据集

实地观察、问卷、访谈、人工计数、照片采样、地图标注、网页信息采集等。

记录：采样设计、采样时间地点、对象定义、采集工具、操作人员、纳入排除标准、偏差与伦理/隐私风险。涉及个人信息时进行必要匿名化并遵守适用规范。

## 建议目录

- `public-datasets/`：公共数据原始文件与来源说明。
- `literature/`：文献目录、摘录与引用信息。
- `self-collected/`：自建数据、采集表与方法记录。
- `source-register.csv`：统一来源登记表。

## 来源登记表字段

`source_id,source_type,title,author_or_org,url_or_doi,published_at,accessed_at,license,coverage,notes`

## 质量检查

- 数据是否与研究问题相关？
- 时间、地域、样本和统计口径是否一致？
- 是否存在重复、缺失、异常值或幸存者偏差？
- 是否能追溯到原始来源？
- 是否允许公开、改编和再分发？
- 不同来源数据能否合法、合理地合并？

## 阶段出口

形成可追溯的数据来源清单，明确哪些数据可直接使用、需要清洗、需要补采或无法使用。
