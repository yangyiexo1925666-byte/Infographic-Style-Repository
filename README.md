# 信息图形风格资料库

本仓库用于系统整理信息图形（Infographic）的数据逻辑、视觉编码、信息架构、视觉叙事方法与案例分析。理论文档与案例档案分离维护；理论目录通过相对链接引用案例目录。

## 目录结构

- `01-信息图形数据逻辑/`：五类基础数据逻辑与设计方法。
- `02-信息图形类型案例/`：混合型、文字/列表型、时间轴型案例规范与分析模板。
- `03-案例素材/`：后续经确认可公开使用的案例图片及来源记录（当前暂不收录未提供的图片）。

## 使用原则

1. 每个案例单独建档，记录来源、作者、年份、媒介与版权状态。
2. 分析区分事实、推断与设计建议，不虚构数据或来源。
3. 理论文档沉淀可复用原则，案例文档保存具体证据与推导过程。
4. 新案例录入后，回写相关理论文档和案例索引。

## 案例提交流程

阅读 `02-信息图形类型案例/案例录入与知识回写规范.md`，复制 `02-信息图形类型案例/案例分析模板.md` 开始录入。
