# 信息图形风格与方法资料库

本仓库用于系统整理信息图形（Infographic）的数据逻辑、统计图形、视觉编码、信息架构、视觉叙事方法与案例分析。理论文档与案例档案分离维护；理论目录通过 Markdown 相对链接连接案例目录。

## 目录结构

- [01-信息图形数据逻辑](./01-信息图形数据逻辑/README.md)：五类基础信息组织逻辑与设计方法。

## 案例录入与更新

案例统一使用[案例分析模板](./02-信息图形类型案例/案例分析模板.md)，并遵循[案例录入与知识回写规范](./02-信息图形类型案例/案例录入与知识回写规范.md)。新案例完成五维分析后，更新[案例索引](./02-信息图形类型案例/案例索引.md)，再将有证据支持的可复用原则回写到相关理论文档。

## 研究原则

- 区分可观察事实、来源明确的信息、分析推断与待核实内容。
- 不虚构案例、数据、统计口径、来源或标准编号。
- `01-信息图形数据逻辑/` 仅保存理论 Markdown，不存放案例图片；通过相对链接连接案例。
- 未经授权不公开转载案例图片，优先记录原始链接、作者与版权信息。
- 案例积累后持续修订理论，单一案例的观察不直接当作普遍规律。
