## 目录结构
- [01-信息图形数据逻辑](./01-信息图形数据逻辑/README.md)：五种基础信息组织逻辑。
- [02-信息图形类型案例](./02-信息图形类型案例/README.md)：17 种市场表现标签、案例、模板与归档规范。
- [03-ISOTYPE信息图](./03-ISOTYPE信息图/README.md)：ISOTYPE 历史、图符语言、信息转译与设计实践专项。

- [05-Gestalt视觉组织原则](./05-Gestalt视觉组织原则/README.md)：12 项首期研究条目、知觉组织与设计应用。

## 案例归档流程
原图核验 → 唯一基础主归属 → 02 表现标签 → 数据集与数据字典 → A–E 五维分析 → 来源/版权记录 → 理论回写 → 索引核验。

## 研究原则
- 区分可观察事实、来源明确、分析推断和待核实内容。
- 不虚构案例、数值、来源、统计口径或作者制作过程。
- CSV 一行一个最小记录单元、一列一个原子字段、一个单元格一个值。
- 未经授权不公开转载案例图片；外链不等于本地存档。
- 单一案例形成观察，不直接上升为普遍规律。
