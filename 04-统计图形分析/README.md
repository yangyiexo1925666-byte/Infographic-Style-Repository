# 04｜统计图形分析

## 目录定位

本目录研究信息图形所使用的统计图形与数据处理方法，重点回答：源数据需要怎样的结构、字段如何转换和聚合、统计图形如何选择、视觉变量如何映射，以及图表何时会误导读者。

**边界：** 04 的图表类型不是 01 的基础信息逻辑，也不是 02 的市场表现标签。一个案例可以同时有“层级型”基础逻辑、“比较型”表现标签，并使用条形图、点图或比例符号图。

## 建议的研究分类

1. **比较与排序图：** 条形图、点图、斜率图、哑铃图、坡度图。
2. **时间序列图：** 折线图、面积图、阶梯图、日历热力图。
3. **组成与部分整体图：** 堆积条、百分比堆积条、饼图/环形图、矩形树图。
4. **分布图：** 直方图、箱线图、小提琴图、密度图、蜂群图。
5. **关系图：** 散点图、气泡图、相关矩阵、网络图。
6. **地理统计图：** 分级设色图、比例符号地图、点密度图、流向图、格网图。
7. **多变量与高维图：** 平行坐标、小倍数、雷达图（谨慎）、降维投影。
8. **象形与图像统计：** 点阵图、象形统计图、比例符号阵列；需说明图符数量/面积/大小的映射方式。

以上是本库的工作目录建议，不宣称为唯一或穷尽的统计图表分类。

## 每种图表的标准研究卡片

每种图表应说明：
- 适用的数据类型与分析问题；
- 最小数据结构（一行代表什么、字段含义、单位）；
- 数据预处理、聚合、归一化、排序与计算；
- 视觉通道映射（位置、长度、面积、角度、颜色、形状）；
- 轴、基线、刻度、分箱、图例和标注规范；
- 常见误读、适用边界与替代图表；
- 至少一个可追溯案例及来源。
