# 04-统计图形分析

## 目录定位

本目录研究信息图形案例中借用的统计图形，重点从源数据结构出发，识别统计图形的字段要求、数据转换与聚合计算、视觉编码及适用边界。

本目录关注的问题包括：

- 统计图形需要怎样的源数据表结构？
- 每个字段承担什么作用，哪些字段是必需的？
- 数据在绘制前需要进行怎样的清洗、转换、排序或聚合计算？
- 数据字段如何映射到位置、长度、面积、颜色、形状等视觉通道？
- 图形适合表达什么问题，又有哪些误读风险与适用边界？

## 与现有目录的关系

- **01-信息图形数据逻辑**：整理五种基础信息组织逻辑，是本资料库的基础类型学。
- **02-信息图形类型案例**：存放信息图形案例原图、案例分析文档及类型案例资料。
- **ISOTYPE 专项方法**：目前归档于 [02-信息图形类型案例/00-基础设计方法/ISOTYPE-象形统计与符号化信息设计方法.md](../02-信息图形类型案例/00-基础设计方法/ISOTYPE-象形统计与符号化信息设计方法.md)。它是可跨类型调用的象形统计与信息转译方法，不等同于某一种统计图形。
- **03-Gestalt格式塔视觉组织原则**：整理视觉组织与知觉分组原则，为图形布局、信息层级和视觉关系分析提供理论依据。
- **04-XXX主题信息图形设计**：记录将知识应用于具体主题的项目工作流。
- **05-信息图表设计基础与方法**：整理信息图表基础、数据类型、视觉编码、数据伦理、交互体验与设计评估等基础知识。

统计图形分析与 01 的基础信息组织逻辑属于不同分析层次：本目录解释案例“借用了什么统计图形、需要什么样的数据表、如何进行计算和视觉编码”，不取代 01 的五种基础类型学分类。
