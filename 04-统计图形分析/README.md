# 04-统计图形分析

## 目录定位

本目录研究信息图形案例中借用的统计图形，重点从源数据结构出发，识别统计图形的字段要求、数据转换与聚合计算、视觉编码及适用边界。

本目录关注的问题包括：

- 统计图形需要怎样的源数据表结构？
- 每个字段承担什么作用，哪些字段是必需的？
- 数据在绘制前需要进行怎样的清洗、转换、排序或聚合计算？
- 数据字段如何映射到位置、长度、面积、颜色、形状等视觉通道？
- 图形适合表达什么问题，又有哪些误读风险与适用边界？

## 与现有目录的关系

- **[01-信息图形数据逻辑](../01-信息图形数据逻辑/README.md)**：整理五种基础信息组织逻辑，是本资料库的基础类型学。
- **[02-信息图形类型案例](../02-信息图形类型案例/README.md)**：存放信息图形类型说明、案例分析模板、索引与案例档案。
- **[03-ISOTYPE信息图](../03-ISOTYPE信息图/README.md)**：研究象形统计、标准化图符与信息转译方法；象形符号图可与 ISOTYPE 方法关联，但二者不等同。
- **[05-Gestalt视觉组织原则](../05-Gestalt视觉组织原则/README.md)**：整理视觉组织与知觉分组原则，为图形布局、信息层级和视觉关系分析提供理论依据。
- **[06-XXX主题信息图形设计](../06-XXX主题信息图形设计/README.md)**：记录将知识应用于具体主题的项目工作流，并在其中调用基础设计方法。

统计图形分析与 01 的基础信息组织逻辑属于不同分析层次：本目录解释案例“借用了什么统计图形、需要什么样的数据表、如何进行计算和视觉编码”，不取代 01 的五种基础类型学分类。
