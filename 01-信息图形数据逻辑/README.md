# 01｜信息图形数据逻辑

本目录存放五类基础信息组织逻辑的理论文档，不保存案例图片。每件案例必须选择**唯一主归属**；其他同时出现的逻辑记录为辅助逻辑。

## 五类基础逻辑
1. [编年型](./01-编年型信息图形概念定义.md)：以具有事实约束的顺序、阶段或时间进程为主。
2. [层级型](./02-层级型信息图形概念定义.md)：以父子包含、从属、等级或优先级为主。
3. [编目型](./03-编目型信息图形概念定义.md)：以对象分类、类别归属和可检索集合为主。
4. [字母表型](./04-字母表型信息图形概念定义.md)：以规范化名称/索引键排序支持检索。
5. [地理图型](./05-地理图形信息图形概念定义.md)：以位置、区域、距离、邻接或空间连接为主。

## 判定规则
- 先问作品主要回答什么信息问题，再判断主导关系。
- 仅有从左到右的版式顺序，不足以判为编年型。
- 仅有大小、字号或装饰差异，不足以判为层级型。
- 普通并列清单不自动构成分类；编目型需有对象集合和分类/检索依据。
- 数值排名若主要表达等级或优先级，可判层级型；单纯按数值排序展示则需结合主要阅读任务判断。
- 地图外观不自动构成地理图型，空间位置必须参与信息解释。
- 不确定时标记“待分类”，不要为了填满标签强行归类。
