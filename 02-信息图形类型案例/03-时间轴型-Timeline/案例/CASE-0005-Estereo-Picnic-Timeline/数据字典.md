# 数据字典｜CASE-0005 Estéreo Picnic

## 数据状态
本 CSV 为图面可读信息转录表，不是已核验的原始数据集。年份节点和 2018 年底部摘要按图面录入；观众规模数字仅录入可见数值，因压缩图像不足以可靠确认其与各年份的对应关系，year 字段留空。音乐类型、参演艺人和国家/地区完整明细尚未录入。

## 记录粒度
- edition：一行代表一个图面年份节点。
- festival_summary：一行代表一个 2018 年摘要指标。
- attendance_value：一行代表一个可辨认的观众规模数值；年份未确认。

## 字段定义
| 字段 | 类型 | 单位/格式 | 说明 |
|---|---|---|---|
| record_id | string | — | 记录唯一 ID |
| record_type | string | — | edition、festival_summary 或 attendance_value |
| year | integer | 年 | 图面年份；无法确认时留空 |
| metric | string | — | 指标名称 |
| value | number/string | 依指标而定 | 图面可读值 |
| unit | string | — | count、artists、people、USD 或日期格式 |
| category | string | — | 类别；未确认时留空 |
| source_status | string | — | 图面转录状态 |
| notes | string | — | 口径、映射和核验限制 |

## 数据核对与限制
- 图面可见年度节点：2010 至 2018，共九个年份。
- 图面底部摘要可读：3 个场景、3 月 23—25 日、30 位国际艺人、25 位国内艺人、55 位艺人、300 万美元艺人投资。
- 30 + 25 = 55，算术一致；不代表艺人分类口径已获独立核验。
- 观众规模可读值录入为独立记录，但年份留空，不凭空间邻近关系推断年份。
- 音乐类型条形数值、国家/地区统计和艺人逐届清单未建立完整数据表。
- 投资金额的币种、预算范围、统计定义和实际支出/预算属性待核实。

## 缺失值规则
- 空 year 表示当前图像无法可靠确认该观众数值对应的年份，不代表数值为零。
- 不根据条形长度、圆形面积或像素位置反推精确数值。
- 原始数据获得后，应分别建立年度、艺人参演关系、音乐类型、国家来源及观众规模表。
