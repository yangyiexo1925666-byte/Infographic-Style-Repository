# 02｜信息图形类型案例（17 种市场表现标签）

**01 的五种基础信息组织逻辑是唯一基础类型学**：编年型、层级型、编目型、字母表型、地理图型。02 只记录市场应用、媒介与视觉表现形式，不构成第二套基础类型学。每个案例必须选择一个基础主归属，其余逻辑列为辅助；表现标签可按证据多选。

## 17 种表现标签

| 编号 | 表现标签 | 说明 |
|---|---|---|
| 01 | [混合型 Mixed Charts](./01-混合型-Mixed-Charts/00-标签说明.md) | 多种图表、图像与文字组合 |
| 02 | [文字型/列表型 Informational / List](./02-文字型列表型-Informational-List/00-标签说明.md) | 清单、说明、知识点和条目 |
| 03 | [时间轴型 Timeline](./03-时间轴型-Timeline/00-标签说明.md) | 时间或阶段序列的视觉呈现 |
| 04 | [示意图型 How-to](./04-示意图型-How-to/00-标签说明.md) | 构件、动作、步骤与操作解释 |
| 05 | [流程图型 Process](./05-流程图型-Process/00-标签说明.md) | 节点、步骤、转移和依赖关系 |
| 06 | [比较型 Comparison](./06-比较型-Comparison/00-标签说明.md) | 同口径对象、指标或观点对照 |
| 07 | [地标型 Location](./07-地标型-Location/00-标签说明.md) | 地名、地图、位置和路线 |
| 08 | [图片式 Photo-graphic](./08-图片式-Photo-graphic/00-标签说明.md) | 摄影图像作为主要信息载体 |
| 09 | [层级表现型 Hierarchical](./09-层级表现型-Hierarchical/00-标签说明.md) | 树状、嵌套、主次或包含的视觉呈现 |
| 10 | [单一图表型 Single Chart](./10-单一图表型-Single-Chart/00-标签说明.md) | 单一核心统计图表 |
| 11 | [文字可视化 Visualized Text](./11-文字可视化-Visualized-Text/00-标签说明.md) | 文字形态本身承担视觉编码 |
| 12 | [解剖型 Anatomical](./12-解剖型-Anatomical/00-标签说明.md) | 对象内部结构、剖面与部件标注 |
| 13 | [视觉简历 Visual Resume](./13-视觉简历-Visual-Resume/00-标签说明.md) | 个人经历、技能与成果可视化 |
| 14 | [手稿型 Hand-drawn](./14-手稿型-Hand-drawn/00-标签说明.md) | 手绘媒介/视觉风格 |
| 15 | [编年编目复合表现 Hybrid](./15-编年编目复合型-Hybrid/00-标签说明.md) | 时间序列与类别清单组合 |
| 16 | [三维型 3D](./16-三维型-3D/00-标签说明.md) | 三维模型、透视或轴测表现 |
| 17 | [词云 Word Cloud](./17-词云信息图-Word-Cloud/00-标签说明.md) | 词项以字号、位置、方向等视觉化 |

> 01–16 为参考库沿用的表现标签框架；17 词云为补充标签。该体系是工作用检索分类，不宣称穷尽所有信息图表现形式。各标签的适用边界见对应说明文档。

## 统一案例结构

```text
02-信息图形类型案例/
└── 表现标签/
    ├── 00-标签说明.md
    └── 案例/
        ├── README.md
        └── CASE-0001-作品名/
            ├── 分析.md
            ├── 原图来源.md
            ├── 基础数据集.csv
            └── 数据字典.md
```

原图仅在确认公开再发布权利后保存；否则使用“原图来源.md”记录官方链接、作者、版本、访问日期与权利状态，并明确原图未上传。每个案例只保留一份主档，其他标签通过索引链接，不复制多份。
