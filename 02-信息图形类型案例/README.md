# 02 信息图形类型案例

本目录归档具体案例、类型说明、分析模板与知识回写记录。每个案例应有可追溯来源，并区分可观察事实、来源明确的信息与分析推断。

## 分类说明

本目录区分两种不同层级的标签：**信息图形类型**描述信息如何组织与呈现；**基础设计方法**描述可跨类型调用的视觉表达方法。ISOTYPE 专项研究已独立归档，不与时间轴型、混合型等类型并列。

## 目录约定

每个案例单独建目录，至少包含 `analysis.md` 与来源记录。未经授权的图片不直接上传仓库，可记录原始链接、作者、标题、版权状态和访问日期。理论目录只放文字与相对链接，不复制案例图片。
