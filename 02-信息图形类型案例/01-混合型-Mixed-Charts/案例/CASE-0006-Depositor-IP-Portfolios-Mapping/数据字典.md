# 数据字典｜CASE-0006 Depositor IP Portfolios Mapping

## 数据状态
当前 CSV 只转录图面清晰可辨的机构名称和相邻数字。数字的业务定义、单位、统计时间和来源均未核实；中央每条曲线的完整起终点关系也未从当前分辨率图像恢复。此文件不是完整映射数据集。

## 记录粒度
当前 CSV 一行代表一个图面机构标签及其相邻数字。后续完整数据应拆分为机构表、技术组合表、技术需求表和映射关系表。

## 当前字段
| 字段 | 类型 | 单位/格式 | 说明 |
|---|---|---|---|
| record_id | string | — | 机构记录 ID |
| record_type | string | — | 当前为 organization |
| name | string | — | 图面机构名称 |
| visible_count | number | — | 图面机构旁数字，定义待核实 |
| unit | string | — | 单位未提供，留空 |
| source_status | string | — | 图面可见状态 |
| notes | string | — | 口径限制 |

## 建议的完整数据模型
- organizations：organization_id、organization_name
- portfolios：portfolio_id、organization_id、portfolio_name
- technology_needs：need_id、need_name、technology_category
- mappings：mapping_id、portfolio_id、need_id、relationship_type、evidence_source
- industry_categories：industry_id、industry_name、icon_reference

## 数据纪律
- 一行一条记录；映射表一行代表一条真实关联。
- 不把图面曲线数量当作组合数量，除非数据说明证实。
- 不把机构旁数字擅自解释为技术组合总数或专利数。
- 不凭线条颜色和交叉点补造映射关系。
