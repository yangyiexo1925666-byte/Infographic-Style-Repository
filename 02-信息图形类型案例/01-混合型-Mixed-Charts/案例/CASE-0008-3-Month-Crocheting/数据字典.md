# 数据字典｜CASE-0008 3 Month Crocheting

## 数据状态
当前 CSV 仅记录图片中可直接辨认的四项汇总指标与三个时间维度。商品级制作记录、销售订单、Etsy 统计数值和地图位置关系未从图片中可靠恢复。不得用图形面积、曲线数量或位置猜测精确数据。

## 当前 CSV 字段
| 字段 | 类型 | 单位/格式 | 说明 |
|---|---|---|---|
| record_type | string | — | summary 或 time_dimension |
| record_id | string | — | 当前记录唯一编号 |
| field | string | — | 指标或维度字段名 |
| value | string/number | — | 图面可见值 |
| unit | string | — | 指标单位；未知时留空 |
| period | string | — | 统计周期；年份未知 |
| source_status | string | — | 图面可见或待核实 |
| notes | string | — | 口径说明 |

## 建议完整数据模型
- items：item_id、item_name、image_ref、category
- making_records：record_id、item_id、date、month、crochet_hours
- sales：sale_id、item_id、sale_status、sale_date、order_id
- locations：location_id、country、region、latitude、longitude
- item_location_links：item_id/order_id、location_id、relationship_type、evidence_source
- metrics：metric_name、metric_value、unit、period、definition

## 关键口径
- “Items: 22”与“Of them sold: 16”是图面标注，不推断其余 6 件商品的具体状态。
- “Crochet time [h]: 96”按图面转录为 96 小时，统计周期为图面所示三个月；详细汇总口径待核实。
- “Max. crochet time in the day [h]: 10”按图面转录为单日最大钩织时长 10 小时。
- 地图连接点暂不解释为买家、订单收件人或物流目的地。
- 标准 Alluvial 流带宽度须有数值字段支持；本案尚未取得完整原始数据。
