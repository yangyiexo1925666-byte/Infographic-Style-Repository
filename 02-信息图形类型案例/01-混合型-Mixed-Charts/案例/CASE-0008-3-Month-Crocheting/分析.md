## 3. 五维分析

### A. 基本数据逻辑
**唯一主归属：编年型。** 图面以 January、February、March 三个月份作为首要组织框架，商品制作记录依附于时间段展开，时间构成主要叙事入口。

**辅助逻辑：**
- 编目型：每件钩织商品作为独立对象，配有商品图像与制作时间信息。
- 地理图形型：世界地图用于定位下游的地理关联结果；地图不承担完整的地理统计分类主结构。

### B. 统计图形与计算方式
- 中央部分采用垂直条形/色块表达商品在 Etsy 相关统计中的分布或数值；图面标题 “items on etsy” 可见，但具体指标和单位需原始数据核实。
- 上部到中部的宽幅彩色带用于视觉追踪商品或月份记录与中央统计项之间的关联。
- 中部到地图的细曲线表现统计项与地理位置之间的连接。
- 由于无法确认带宽是否严格映射数量，也无法确认流量是否满足总量守恒，当前不将其登记为标准 Sankey 或标准 Alluvial。
- 更稳妥的名称为“多层关联流图（Alluvial 风格）+ 条形统计 + 地理连接图”。

### C. 视觉编码
- **时间位置：** 月份以顶部横向分段呈现。
- **颜色：** 不同商品/记录使用多种低饱和颜色；是否严格一色对应一个商品需结合原始图例或数据核实。
- **流带：** 宽幅曲线把上部商品记录与中部统计结构关联起来。
- **条形：** 中部竖向条形提供集中比较区域。
- **地理位置：** 世界地图使用灰色弱化处理，彩色曲线成为主要连接信息。
- **图像：** 商品实物缩略图将抽象统计与具体制作对象联系起来。
- **版式：** 纵向长幅构图，形成“时间与商品—统计—地理位置”的自上而下阅读路径。

### D. 数据／信息架构
建议将数据拆分为可关联的数据表：
1. **商品表：** item_id、item_name、image_ref、category。
2. **制作记录表：** record_id、item_id、date、month、crochet_hours。
3. **销售记录表：** sale_id、item_id、sale_status、sale_date、order_id。
4. **地理记录表：** location_id、country、region、latitude、longitude。
5. **商品—地理关联表：** item_id 或 order_id、location_id、relationship_type、evidence_source。
6. **汇总指标表：** metric_name、metric_value、unit、period、definition。

数据纪律：一行一条记录、一列一个字段、一格一个值；不能把商品列表、多个国家或多条订单关系塞进同一单元格。只有获得可核验数据后，才可重建流带宽度和地图连接。

### E. 视觉叙事架构
- **第一层：时间与商品。** 通过三个月份组织商品制作记录。
- **第二层：统计汇总。** 中央条形/色块集中呈现 Etsy 相关项目的数量或分布。
- **第三层：地理关联。** 世界地图展示商品记录与地理位置之间的关系。
- **阅读路径：** 何时制作 → 制作了哪些商品 → 商品在平台统计中的情况 → 关联到哪些地理位置。
- 该叙事路径是对版面组织的解释，不代表已核实的实际交易或物流过程。

## 4. 可迁移的设计方法
### 方法一：时间—对象—空间三层叙事
- 适用：个人创作记录、手工艺生产、独立商店运营、项目制作与传播。
- 做法：时间轴作为入口，对象目录作为中层，地图或空间关系作为结果层。
- 关键：各层必须通过唯一对象 ID 或交易 ID 关联，不能只依靠装饰性连线。

### 方法二：商品缩略图嵌入时间记录
- 适用：作品集进度、产品开发、手作生产、设计过程记录。
- 做法：在月份/时间段中嵌入对象缩略图和制作时长。
- 风险：缩略图数量过多时应统一尺寸、控制标签密度。

### 方法三：连续曲线追踪对象关系
- 适用：多阶段分类、商品与平台指标、产品与地理分布关联。
- 做法：用一致颜色追踪同一对象跨越不同信息层。
- 风险：线条交叉、颜色混淆和关系误读；应提供图例、端点标签或交互高亮。

### 方法四：地图作为末端关联视图
- 适用：销售区域、受众分布、项目地点、创作传播范围。
- 做法：地图置于叙事末端，以细线连接上游记录。
- 风险：若地理位置仅是用户所在地或访问来源，不应将其描述为物流流向。

## 5. 设计生成参考提取
- **画幅：** 纵向长幅信息图。
- **背景：** 暖白/浅米色纸感底色。
- **顶部：** 三个月份横向分组，每组放置商品缩略图、小时数和小型色块。
- **中部：** 垂直条形统计区，标签简洁，左右留出刻度与辅助标注。
- **连接结构：** 从顶部商品记录向中部统计区延展多条平滑、宽幅、低饱和色带；再以细曲线连接到底部世界地图。
- **底部：** 浅灰世界地图，保留必要地理端点和细线。
- **色彩：** 灰绿、暗红、砖红、灰蓝、浅黄、粉紫等低饱和颜色；同一对象跨层保持一致色彩。
- **字体：** 标题使用具有编辑设计气质的衬线/窄体字体，注释使用清晰小字号无衬线字体。
- **生成约束：** 仅生成布局与风格草图；真实数据、商品图、地图坐标和连接关系应由结构化数据确定，不能让图像模型虚构精确统计或地理路径。

## 6. 理论回写与关联
- 表现标签：混合型；时间轴型；地理/地图型。
- 五类基础逻辑唯一主归属：[编年型信息图形](../../../../01-信息图形数据逻辑/01-编年型信息图形概念定义.md)。
- 辅助逻辑：[编目型信息图形](../../../../01-信息图形数据逻辑/03-编目型信息图形概念定义.md)、地理图形型（以现有五类基础逻辑文档名称为准）。
- 相关图表：条形图、多层关联流图、地理连接图。
- Alluvial 术语边界：标准 Alluvial 图通常由多个分类维度/轴、类别节点与流带构成，流带宽度按数量或比例编码；本图当前未核实这些严格条件，因此只标注为 Alluvial 风格，不作标准图表认证。
