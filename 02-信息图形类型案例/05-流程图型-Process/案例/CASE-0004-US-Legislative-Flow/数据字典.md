# 数据字典｜CASE-0004 US Legislative Flow

## 数据状态
当前 CSV 仅转录用户上传图片中清晰可辨的汇总数量。没有原始数据文件、出版来源、统计年份或完整高清州级分流信息。不能把空字段解释为 0，也不能依据流带粗细推算州级数值。

## 记录粒度
- record_type=stage：一行代表一个法案流转阶段的图面汇总值。
- record_type=outcome：一行代表一个签署结果分类的图面汇总值。
- 州级类别：尚未录入完整数据；未来应另建州级明细表，一行一个州，避免与阶段汇总混合。

| 字段 | 类型 | 单位 | 说明 |
|---|---|---|---|
| record_id | string | — | 记录唯一 ID |
| record_type | string | — | stage 或 outcome |
| stage_order | integer | — | 图面阶段顺序；结果分类使用 6 |

| category | string | — | 结果分类名称；阶段汇总留空 |
| source_status | string | — | 数值来源状态 |
| notes | string | — | 转录限制和说明 |

## 缺失值规则
