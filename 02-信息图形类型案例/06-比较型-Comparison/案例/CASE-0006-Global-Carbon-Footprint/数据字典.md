# 数据字典｜CASE-0006 Global Carbon Footprint

## 数据状态
本文件为根据用户提供的低分辨率案例图制作的可见标签转录表，不是原始排放数据集。当前没有可靠读取到各国排放数值、单位、年份和气体口径，因此这些字段保持空值。CSV 仅列出图中较清晰可辨认的国家/地区名称，非完整名单。

## 记录粒度
一行代表一个图面上可辨认的国家或地区对象。

## 字段定义
| 字段 | 类型 | 单位/格式 | 说明 |
|---|---|---|---|
| record_id | string | — | 本案例内记录 ID |
| country_or_area | string | — | 图面国家/地区标签 |
| region | string | — | 按图例颜色识别的区域类别；个别边界需核实 |
| emissions_value | number | — | 排放总量；当前未读取 |
| emissions_unit | string | — | 排放单位；待核实 |
| reference_year | integer | 年 | 统计年份；待核实 |
| gas_scope | string | — | CO₂ 或 CO₂e 等口径；待核实 |
| source_status | string | — | 当前证据状态 |
| notes | string | — | 额外核验说明 |

## 图例区域
图面可见九类：Africa、Asia、Caribbean、Central America、Europe、Middle East、North America、Oceania、South America。

## 数据纪律
- 不通过圆形直径或面积估算排放值。
- 不把圆形位置解释为地理坐标。
- 不把相邻圆形解释为国家间关系。
- 不擅自补入统计年份、排放单位或温室气体范围。
- 当获得原始数据后，应补录 emissions_value、emissions_unit、reference_year、gas_scope 和 source_id，并核验区域归类。
