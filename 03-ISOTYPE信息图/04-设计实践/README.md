# 04 设计实践

## 实践流程
1. 明确传播对象、读者任务与核心问题；
2. 定义数据对象、统计单位、分类口径和数据来源；
3. 建立图符清单与图符语法；
4. 制定数量映射、单位、换算和取整规则；
5. 组织符号阵列、比较关系与阅读路径；
6. 添加图例、标题、注释、来源和限制说明；
7. 进行识别性、数量理解与可读性测试；
8. 记录问题、迭代结果与可复用经验。

## 数据与质量检查
- 一行一记录、一列一字段、一格一值；
- 原始数据与设计映射数据分层保存；
- 数值图符标注单位和换算规则；
- 不以不等比例拉伸图形暗示数量；
- 保留数据来源、处理过程和版权记录；
- 将测试结果与主观设计判断分开。
