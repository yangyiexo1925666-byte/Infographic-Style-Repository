# 03 案例研究

本目录用于建立可追溯的 ISOTYPE 案例档案。当前真实案例数量为 **0**，本 README 仅为研究入口，不代表案例已完成核验。

## 案例分类
1. 历史原作：有可靠史料证明属于 ISOTYPE 体系或其历史实践；
2. 方法延续：有明确来源证明现代作品采用或继承了 ISOTYPE 方法；
3. 风格启发：仅在视觉形式上受到象形统计或 ISOTYPE 风格影响，不归为 ISOTYPE 原作或方法应用。

单案记录案例名称、作者/机构、年代、原始出处、作品版本、数据对象、图符系统、数量编码、版式结构、阅读路径、证据等级、版权状态、分析结论与待核实问题。没有可靠来源时，不将作品归类为 ISOTYPE 历史原作或方法应用。
