# 03 ISOTYPE 信息图专项研究

本目录是 ISOTYPE（International System of Typographic Picture Education，国际图像文字教育系统）及其前身维也纳图像统计法的独立研究项目。它不是新的基础信息图形类型，也不是 `02-信息图形类型案例/` 中的表现标签。

## 研究范围
- 历史来源、发展脉络与重要文献；
- 标准化图符、图像语法与符号系统；
- 信息转译、重复象形单位与数量表达；
- 数据结构、视觉变量与编码规则；
- 有来源支持的历史原作与现代案例；
- 可复用的设计实施流程、检查标准与实验记录。

## 目录结构
- [00-ISOTYPE概念与方法](./00-ISOTYPE概念与方法.md)：专项总论。
- [01-历史与文献](./01-历史与文献/README.md)：历史脉络、人物、出版物与原始文献。
- [02-图符语言与视觉编码](./02-图符语言与视觉编码/README.md)：图符规范、符号语法、数据映射与数量表达。
- [03-案例研究](./03-案例研究/README.md)：真实案例来源、证据等级与结构化分析。
- [04-设计实践](./04-设计实践/README.md)：设计流程、数据规范、测试与实践记录。

## 与其他目录的关系
- `01-信息图形数据逻辑/`：五种基础信息组织逻辑仍是资料库主分类。
- `02-信息图形类型案例/`：记录具体类型与案例；ISOTYPE 不再作为其子标签。
- `04-统计图形分析/`：研究统计图形与数据结构；象形符号图可与 ISOTYPE 方法关联，但二者不等同。
- `05-Gestalt视觉组织原则/`：讨论视觉分组与知觉机制，可检验图符系统可读性。
- `06-XXX主题信息图形设计/`：主题项目可在视觉编码与实践阶段引用本专项方法。

## 研究边界与记录规范
- 信息转译不是装饰性图标替换，必须说明数据对象、语义关系和编码规则。
- 区分历史原作、可证实采用 ISOTYPE 方法的现代作品，以及仅受其视觉风格启发的设计。
- 数值图符必须注明单位、换算比例与取整规则。
- 数据表坚持一行一记录、一列一字段、一格一值。
- 记录来源、作者/机构、年代、版本、出处、访问日期与版权状态。
- 尚未核验的案例与实验不得标记为已完成；分析推断须与来源事实分开。
