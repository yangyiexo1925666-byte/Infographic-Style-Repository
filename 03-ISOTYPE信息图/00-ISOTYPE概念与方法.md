# ISOTYPE 概念与方法

<badge>专项研究总论</badge>

## 1. 研究对象与定位

**ISOTYPE（International System of Typographic Picture Education，国际图像文字教育系统）及其前身维也纳图像统计法**是本专项的研究对象。它不是新的基础信息图形类型，也不是 `02-信息图形类型案例/` 的表现标签；本目录作为独立研究项目，系统考察其历史来源、图符语言、信息转译、数据与视觉编码及设计实践。

## 2. 核心思想

ISOTYPE 的关键不只是“使用图标”，而是建立一套可理解、可重复、具有规则的图像符号系统，将复杂信息转化为大众能够快速识别和比较的视觉表达。

典型原则包括：

- **图像符号代表对象：** 用简化、统一的象形图形指代人物、物品、活动或社会现象。
- **重复表达数量：** 通过符号重复的数量表达统计数量，或以明确图例说明一个符号代表多少单位。
- **统一视觉语法：** 同一套符号在形态、比例、方向、线条和使用规则上保持一致。
- **图文协同：** 标题、标签、图例、注释和简短文字帮助读者理解符号及数据口径。
- **面向公众传播：** 优先考虑识别性、可读性、可比较性和跨语言理解。

## 3. 方法构成

### A. 数据逻辑

先明确统计对象、分类单位、计数口径、时间/地域范围和比较维度。一个图形符号必须对应清晰的对象或统计单位。

### B. 符号设计

- 选择具有辨识度的对象特征进行概括。
- 建立统一的造型风格、比例、视角和细节等级。
- 避免同一符号承担多个互不相关的含义。
- 通过图例明确符号代表“一个对象”还是“一组数量”。

### C. 数量编码

常见方式：
1. **一符号一单位：** 每个图形代表一个对象，重复数量直接对应总量。
2. **一符号多单位：** 每个图形代表固定数量，必须明确标注换算单位。
3. **分数符号：** 部分图形表示不足一个完整单位时，必须说明分数规则。
4. **符号大小编码：** 若用大小表示数量，需特别谨慎；面积与直径并非线性等价，必须给出明确尺度。

不得随意拉伸图形高度或面积来表现数值，否则容易造成数量误读。

### D. 排列与比较

可按类别、时间、地域、群体或等级组织符号阵列。排列顺序应有明确逻辑；需要比较时，尽量保持符号尺寸、间距、基线和分组规则一致。

### E. 视觉叙事

通过符号阵列、分组、对照、序列和注释，呈现规模、差异、构成或变化。符号的排列本身可以形成阅读路径，但不能让装饰性构图掩盖统计关系。

## 4. 与其他视觉系统的区别

| 概念 | 核心作用 | 与 ISOTYPE 的关系 |
|---|---|---|
| 普通图标 | 指代对象或功能 | 可能只是装饰/导航，不必表达数量 |
| 象形统计 | 用重复图像符号表达数量 | 与 ISOTYPE 的方法传统密切相关 |
| ISO 图形符号 | 标准化安全、公共信息或技术识别 | 是另一套标准体系；不能将 ISOTYPE 误称为 ISO 标准 |
| 统计图表 | 编码变量之间的数量关系 | 可与 ISOTYPE 符号系统组合使用 |
| 信息图形类型 | 按信息组织逻辑或呈现方式分类 | ISOTYPE 可跨类型应用，不属于单一类型 |

> 注意：ISOTYPE 中的 “International” 不代表它是 ISO（国际标准化组织）发布的图形符号标准。两者不可混淆。

## 5. 可应用的类型

- **编年型 / 时间轴：** 用符号序列表现不同年份的数量、事件或社会变化。
- **层级型：** 用符号表现不同层级的对象规模或构成。
- **编目型：** 为不同类别建立统一象形符号，并组织成图鉴或分类表。
- **地理型：** 将符号放置在地图上，表现地域分布或地点相关数量。
- **混合型：** 将象形符号阵列与柱状图、地图、时间轴、文字说明等组合。

## 6. 案例分析标签

建议每个案例分别记录：

- 信息组织类型：chronological / hierarchical / catalog / geographic / mixed 等。
- 基础设计方法：ISOTYPE / pictogram system / diagrammatic illustration 等。
- 数量编码方式：one symbol = one unit / one symbol = N units / size encoding / non-quantitative symbol。
- 符号角色：对象指代 / 数量编码 / 分类标识 / 导航提示。
- 图例规则：是否清晰说明符号含义与换算单位。

## 7. 案例分析检查表

- [ ] 图形符号是否对应明确对象或统计单位？
- [ ] 符号形态是否统一且容易识别？
- [ ] 符号重复数量是否与数据一致？
- [ ] 若一个符号代表多个单位，是否明确标注？
- [ ] 是否存在用面积/高度夸大数量的风险？
- [ ] 类别、时间或地域分组是否清晰？
- [ ] 图例、单位、来源与统计口径是否完整？
- [ ] 符号系统是否帮助理解，而非仅作装饰？
