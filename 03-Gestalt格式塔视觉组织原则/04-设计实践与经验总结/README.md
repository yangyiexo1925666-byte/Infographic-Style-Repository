# 设计实践与经验总结

本目录保存格式塔原则在真实设计任务中的实验过程、方案迭代与经验结论。实践经验必须记录具体任务与条件，不把单次结果泛化为普遍定律。

## 建议的实践分类
- 版式优化实践：信息分组、网格、留白、阅读顺序。
- 标志与图形实践：闭合、图底、对称、简洁形式。
- 信息图形实践：数据分组、图例编码、路径和关系表达。
- UI 与交互实践：卡片分区、状态同步、动态反馈、导航关系。

以上分类先作为归档建议；实际项目发生时再建立相应子目录。
