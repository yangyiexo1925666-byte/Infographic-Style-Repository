# 经典原则案例库

本目录用于收集可核验来源的视觉设计案例，并记录作品如何体现一个或多个格式塔组织线索。案例库不以图片堆积为目标，而以可追溯、可比较、可复用的分析记录为核心。

## 内容结构
- 案例索引.md：按原则、媒介和作品类型索引案例。
- 案例录入模板.md：新增案例时复制填写。
- 案例图片与来源记录：建议在本地或有授权的存储空间管理图片；仓库优先保存来源链接、缩略图说明和版权信息。Git 不会保留空目录，首次录入案例时再创建实际文件。

## 收录标准
1. 有可访问的原始作品页面或可靠出处。
2. 能指出画面中具体的组织线索，而非仅凭风格印象判断。
3. 记录作品作者/机构、标题、年份、媒介和来源。
4. 区分作品事实、分析解释与待核实信息。
5. 尊重版权；未经许可不上传完整商业作品图像。
