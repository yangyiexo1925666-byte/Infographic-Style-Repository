# 格式塔原则之间的关联

## 1. 常见协同关系
- **接近 + 相似**：空间靠近与视觉特征一致同时出现时，群组通常更明确。
- **连续 + 平行**：连续路径与一致方向可共同建立阅读轨迹。
- **闭合 + 简洁倾向**：不完整轮廓可能被组织为较稳定、完整的形态。
- **共同区域 + 接近**：容器边界与内部间距共同定义信息模块。
- **连接性 + 接近**：连线可明确表达关系，避免仅凭邻近推断关联。
- **共同命运 + 同步**：动态元素的方向/变化方式与时间一致性可共同强化关联。
- **图底 + 简洁倾向**：主体与背景的分化有助于形成稳定、易识别的整体。

## 2. 分析原则
1. 先区分总体组织倾向、局部分组线索与图底组织。
2. 对每个原则分别指出可观察证据。
3. 说明不同线索是否指向同一分组。
4. 判断最强线索是什么，以及它是否符合内容语义。
5. 用对照版本或用户测试验证解释。

## 3. 注意
以上是设计分析中的常见关系，不表示每一组关系都在任何情境下必然出现。具体效果取决于刺激结构、任务与观看条件。
